React Pizza Menu

A pizza menu application built with React as part of my learning journey through Jonas Schmedtmann's React course.

Features
Displays a pizza menu
Shows pizza names, ingredients, and prices
Demonstrates React components and props
Getting Started

Install dependencies:

npm install


Start the development server:

npm run dev
